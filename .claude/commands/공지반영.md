너는 **"2-3반 관리 마스터" 구글시트 기반 학급 안내 시스템**을 운영한다. 아래 공지 원문을 정리해 반영하라. 이 명령은 자립형이다 — 프로젝트 메모리가 없어도 아래 정보만으로 수행한다. (같은 이름의 메모리 `class-notice-sheet-backend`가 있으면 참고해 최신값 확인.)

## 공지 원문
$ARGUMENTS

- 사용자 = **해성여자고등학교 2학년 3반 담임**(+교과). 학생앱 대상은 **2학년 3반**.
- 비공개 구글시트: **"2-3반 관리 마스터"**, id `1j90BZchA1CaoluBbRhVWV7dwxFalQE6sw_oRxryfqcA`. 탭·헤더(1행):
  - `학급공지` : `대상 | 제목 | 내용 | 날짜 | 긴급`  (대상="전체" 또는 번호CSV "7,12,19" / 긴급=TRUE·FALSE)
  - `체크리스트` : `대상 | 할일 | 마감일`

## 할 일
1. **분류** (2-3반 기준):
   - 학생 안내 → `학급공지` (전체 또는 특정 번호). 특정 학생 지정 시 그 번호를 대상에.
   - 제출/마감일 있는 것 → `체크리스트`.
   - 교사용·비공개·**타학년/교직원/감독 등 학생 무관 건** → `개인업무`.
2. **바로 반영** (컨펌 생략): claude-in-chrome으로 시트를 열어 해당 탭에 **행 추가**.
   - 크롬 미연결 시: 붙여넣을 행을 탭별 표로 제시하고 사용자가 붙여넣게 안내.
3. **검증**: 위 엔드포인트를 `fetch`로 호출해 (a) 학생용 공지가 전체 응답에 있는지, (b) 개인업무 내용이 응답에 **없는지**(유출 0) 확인.
4. **보고**: 무엇을 어느 탭에 넣었는지 간단히. 애매한 항목은 합리적 위치에 넣고 "이건 애매해 X에 넣음"만 알림.

## 시트 쓰기 주의 (지난 실수 방지)
- **1행 헤더를 덮어쓰지 말 것.** 새 행은 기존 데이터 **아래**에 추가.
- 셀 좌표 클릭이 자주 어긋난다 → 안전책: 해당 탭을 `Ctrl+A→Delete`로 비운 뒤 **헤더+기존행+새행 전체를 A1에 한 번에 붙여넣기**(가장 확실). 붙여넣기는 `navigator.clipboard.writeText(TSV)` 후 A1 클릭→`Ctrl+V`. **`Ctrl+Home`은 쓰지 말 것**(탭 분리가 깨짐).
- 코드/전화번호 등 앞자리 0 값은 텍스트로(작은따옴표 접두 `'019596`).
- 붙여넣은 뒤 **열 분리가 됐는지 스크린샷으로 확인**.
