# 2학년 3반 학급 알림장

학생용 학급 안내 사이트입니다. Google Sheets의 `앱_공지사항` 중 관리자가 `게시됨`으로 승인한 항목만 표시합니다.

개인 알림장에서 번호 목록이나 여러 일정이 들어오면 검토함에는 항목별 초안으로 나뉘어 들어옵니다. 관리자는 각 항목을 따로 수정하거나 게시·보류할 수 있습니다.

개인 코드 로그인은 Google Sheets의 `앱_학생목록`을 사용합니다. 예전 `명단(번호·이름·코드)` 탭이 있으면 개인 알림장 Apps Script의 `학급 플래너 → 기존 명단 가져오기`로 이전할 수 있습니다. 관리자 화면은 누락 상태를 경고하고 해당 시트를 여는 버튼을 제공합니다.

관리자 화면은 `/admin/`에 있습니다.

- 주소: `https://morningcandy.github.io/class-notice/admin/`
- 초기 비밀번호: `admin1234`
- 기능: 공지 직접 추가, 수정, 게시, 보류, 종료, 검토 대기로 되돌리기

비밀번호는 브라우저 코드에서 확인하지 않고 Apps Script가 검사합니다. `setupClassPlanner`를 처음 실행할 때만 초기 비밀번호를 만들며, 이후에는 스프레드시트의 `학급 플래너 → 관리자 토큰 설정`에서 바꿀 수 있습니다.

## 학생이 보는 내용

- 로그인 전: 학급 전체 공지와 전체 할 일
- 개인 코드 확인 후: 전체 내용 + 본인에게 지정된 개별 공지와 할 일
- 다른 학생의 이름, 코드, 개별 공지는 응답에 포함되지 않음

학생이 공지 확인 또는 할 일 완료를 체크하면 Apps Script를 통해 `앱_학생응답`에 기록됩니다. 화면의 체크 상태는 해당 브라우저에도 저장됩니다.

## 데이터 흐름

```text
개인 알림장 입력
  → 앱_공지사항의 검토대기
  → 관리자에서 공지/할 일 종류와 내용을 확인·수정한 뒤 게시 승인
  → Apps Script가 게시됨 항목만 필터
  → 학생용 사이트 표시
```

예전의 URL `#import=...` 일정 전달과 공개 `data.js` 공지 저장은 사용하지 않습니다. `data.js`에는 공개 가능한 학사일정만 둡니다.

## 연결 설정

`config.js`의 `apiUrl`에는 개인 알림장과 같은 Apps Script 웹앱 URL을 입력합니다. 학생 화면과 관리자 화면이 이 설정을 함께 사용합니다.

```js
apiUrl: "https://script.google.com/macros/s/배포ID/exec"
```
